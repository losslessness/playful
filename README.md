## <a name="introduction">Introduction</a>

Meet **Playful**, a fictional gaming peripheral ecommerce platform built for learning purposes.

This project is a work in progress and the goal is to be built as if it was a real product, with concerns such as performance, reliability and scalability being taken into consideration.

Once finished, it will offer a complete online shopping experience, offering features such as product browsing, order processing and tracking, an admin dashboard and much, much more.

## <a name="tech-stack">Tech Stack</a>

- **Frontend**: Next.js, TailwindCSS, ShadCN, TypeScript
- **Backend**: Spring Boot
- **Database**: PostgreSQL
- **Authentication**: JWT
- **Payment**: Stripe
